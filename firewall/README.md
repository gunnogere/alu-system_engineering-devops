The script 0-block_all_incoming_traffic_but automates the installation and configuration of the Uncomplicated Firewall (UFW) on Ubuntu systems to secure incoming network traffic. By setting default policies to deny all incoming requests and allow all outgoing traffic, it establishes a default-deny posture. It then selectively opens TCP ports 22 (SSH), 80 (HTTP), and 443 (HTTPS), alongside the OpenSSH profile, ensuring essential management and web serving services remain fully accessible while shielding the system from unauthorized access on unused ports.

Safety and operational continuity are built directly into the script to prevent accidental administrator lockouts. Before enabling the firewall rules non-interactively, the script explicitly stage-loads the SSH rule and displays the queued table for terminal verification. This structured approach ensures firewall rules can be safely deployed across infrastructure nodes like web-01 without interrupting active administrative sessions or blocking subsequent deployment pipelines.
